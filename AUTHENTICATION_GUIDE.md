## 🔐 Authentication Flow

```
User Registration
  ↓
/register endpoint
  ↓
User data stored (in-memory, upgrading to DB is easy)
  ↓
Redirect to /login

User Login
  ↓
Email & password verification against stored users
  ↓
JWT token generated by NextAuth
  ↓
Redirect to /dashboard
  ↓
Server-side session check protects dashboard

User Logout
  ↓
Session cleared
  ↓
Redirect to /login
```

## 📦 User Storage (Current Implementation)

**Currently**: In-memory storage using `lib/users.js`
- Simple array of user objects
- Stores: ID, name, email, password, role, createdAt

**To upgrade to a real database**, modify `lib/users.js`:
- Replace with Prisma (PostgreSQL/MySQL)
- Or use MongoDB with Mongoose
- Or AWS DynamoDB
- Hash passwords with `bcrypt` before storing
- The rest of the code will work unchanged!

## 📝 Environment Variables Needed

Create a `.env.local` file:
```
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your-secret-key-here-min-32-chars
```

Generate a secret:
```bash
openssl rand -base64 32
```
